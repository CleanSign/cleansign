# Roles & Duties

| Role | Duty |
|---|---|
| **Product Manager** (DevOps + Team Leader) | 제품 방향·우선순위·일정 관리, 최종 의사결정 / CI/CD·배포·인프라·모니터링 / 브랜치·릴리즈·리뷰 규칙 |
| **Product Engineer** (Frontend) | `web` UI/UX 구현 / 서버 API 연동, 상태·에러 처리 / 컴포넌트·성능·접근성 관리 |
| **Product Engineer** (Backend) | `server`(Go) API·DB·인증 개발 / ai-service 연동 스펙 관리 / 업로드·보안·로깅 |
| **AI Researcher** | `ai-service` 분석 로직·프롬프트·점수 산출 / 평가 데이터셋·정확도 개선 / 모델·비용·지연시간 최적화 |
| **Operations Manager** | 사용자 문의·피드백 수집 / 법률 도메인 검수·품질 기준 수립 / 약관·개인정보·외부 커뮤니케이션 |

## 협업 경계
- **API 스펙**: Backend 주도, Frontend·AI Researcher 합의
- **배포/인프라**: PM 주도, Backend 지원
- **결과 품질 기준**: Operations 제시, AI Researcher 개선
