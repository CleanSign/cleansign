===== 표 0 =====
임차인 부담비용 = 수선비용 - (시설물경과연수 / 수선주기)   ×   수선비  용 
           * 부분 보수의 경우 임차인 부담비용 = 수선비용 전액 (예컨대 주방가구 중  
         문짝   1개만을 교체하는 경우 등) 
     
         * 시설물경과연수는 해당 시설물의 최초 설치 시점부터 산정한 시설 
         물의 전체 경과연수로서 임차인의 거주기간과 다를 수 있음

===== 표 1 =====
ㅇ   물품 수리 시   = 수리액 - (사용연수/내구연한)   ×   수리액 
   ㅇ   신품 교체 시   = 신규구입가 - (사용연수/내구연한)   ×   신규구입가

===== 표 2 =====
1. 용어의 정의 
     ①   원상회복 : 입주시와 똑같은 상태로 복구하는 것 
     ②   오손   : 더럽히고 손상함 
     ③   파손 :   깨어져 못쓰게 됨 
     ④   훼손 : 헐거나 깨트려 못 쓰게 만듦    
     ⑤   오  ·  파손 : 더럽혀졌거나 깨어져 못쓰게 되는 것 
     ⑥   박리 : 이격되어 떨어지는 것, 벗겨짐 
     ⑦   변색 : 빛깔이 변하여 달라짐 
     ⑧   손모 : 사용함으로써 닳아 없어짐 
     ⑨   부식 :   금속이 외부로부터의 화학작용에 의해서 금속이 아닌 상  태로 
              되어 소모되어 가는 현상 
     ⑩   손상 : 떨어지고 상함 
     ⑪   멸실,망실 : 없어지거나 분실하는 것 
     ⑫   과실 : 어떤 결과의 발생을 부주의로 예견하지 못한 일 
     ⑬   고의 : 일부러 하는 행동이나 생각 
     ⑭   보충 : 모자라는 것을 보태어 채움 
     ⑮   철거 : 시설 등을 걷어치움 
     ⑯   교체 : 교환하는 것 
     ⑰   노후 : 시설물의 내용연수, 수선주기가 경과하여 제구실을 하지 못하는 상태
